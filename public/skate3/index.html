Tricks guide

Use the right stick on a controller or the on-screen pad. On a keyboard, use the arrow keys. Follow each direction in order; diagonal arrows mean two keys together.

Hold the first direction to set up, then flick quickly to the last direction and release. For example: hold ↓, release it, then tap ↑ for an ollie.

Basic flips

Ollie
↓ then ↑ — pop off the tail.
Nollie
↑ then ↓ — pop off the nose.
Kickflip
↓ then ↗ (↑ + →).
Heelflip
↓ then ↖ (↑ + ←).
Nollie kickflip / heelflip
Start at ↑, then flick ↘ / ↙.

These directions follow the bundled gesture layout. Mirrored / switch stance can swap flip names. Return the stick to center between attempts.

Air, grabs & grinds
180 / 360 spin
While airborne, hold the left stick left / right, or A / D. More airtime lets you rotate further.
Grab
In the air, hold LT / RT — keyboard Z / C. Move the right stick / arrows to tweak; release before landing.
Frontflip / backflip
With a grab held in the air, flick the left stick forward / backward. A controller or touch stick gives the small setup movement these gestures need.
Grinds & slides
Ollie onto a rail or ledge and line up the board. Use the right stick / arrows to adjust the board; flick an ollie to pop out.
Manual / nose manual
Gently hold the right stick partway down / up. Use a controller or touch stick: arrow keys cannot hold the required partial deflection.
Landing
Line up with your direction of travel, let go of grabs, and give the board time to finish its flip.
Keyboard / controller controls
Steer / left stick
W A S D.
Flick / right stick
↑ ← ↓ →.
Push
Space = pad A; Left Shift = pad X.
Brake / B button
E = pad B; its action depends on the current riding state.
Y button
F = pad Y.
Triggers / bumpers
Z / C = LT / RT; Q / R = LB / RB.
Session marker
Set: Q + 2 (LB + D-pad down). Return: hold Q + 1 (LB + D-pad up). Touch pad: Set / Go to.
Pause / resume
Esc, controller Start, or the touch Start button.
